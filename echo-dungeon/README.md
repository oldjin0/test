# 메아리 던전 (Echo Dungeon)

60초짜리 한 손 로그라이트. 한 판이 끝나면 **내 움직임이 메아리(유령)로 녹화**되어 다음 판에서 함께 싸우고,
**쓰러지면 나를 쓰러뜨린 몬스터가 내 이름을 달고 진화**해 다음 판에 나타난다.

## 게임 구성 (v0.6)
- **직업 3종**: 타이틀의 캐릭터 단추를 눌러 별도 선택 화면에서 고른다(능력치 막대 포함). 검사(근접·체력 높음·넓은 관통 베기), 궁사(원거리·체력 낮음·빠른 관통 화살), 법사(중거리·터지는 마법 구슬). 메아리는 그 판에 쓴 직업 그대로 재현된다.
- **카드 72장**: 기존 22장 + 새 카드 50장 + 전설 3장(불사조의 깃·천벌·만능의 왕관, 가끔만 나오고 효과가 확실히 크다). 화상·유도·도탄·처형·오라·충격파·재생·회피·메아리 강화 등. 행운 카드는 희귀 이상이 더 자주 나오게 한다.
- **캐릭터 그림**: 플레이어 캐릭터는 앞·뒤·옆모습을 한 번에 그려 같은 캐릭터로 통일했다. 몬스터·보스는 정면 한 장을 자세히 그려 모든 방향에 쓴다.
- **잘 보이는 공격**: 원거리 탄은 어두운 테두리와 후광, 꼬리를 달았고, 적의 탄은 붉은 위험 고리와 꼬리로 구분된다. 해골 마법사는 쏘기 직전 조준선이 깜빡인다.
- **움직임**: 한 장짜리 캐릭터 그림을 머리·몸통·다리로 잘라 움직이는 컷아웃 애니메이션. 다리를 번갈아 딛고, 몸이 튀고, 머리가 한 박자 늦게 따라온다. 이동 방향에 따라 앞·뒤·옆모습이 바뀌고, 박쥐는 날갯짓, 슬라임은 통통 뛴다.
- **손맛**: 때릴 때는 맞은 방향으로 뻗는 섬광, 넉백, 흰 실루엣 번쩍임, 치명타 히트스톱, 처치 고리와 불꽃, 콤보. 맞을 때는 빨간 실루엣, 밀려남, 화면 붉은 번쩍임과 흔들림.
- **배경**: 챕터마다 투기장 전체를 한 장으로 그린 그림. 용암·그림자 무늬가 숨 쉬듯 빛나고 반딧불·불씨·눈송이가 떠다닌다.
- **끝없는 스테이지**: 다섯 챕터를 차례로 돌고, 한 바퀴(깊이)마다 적이 강해지고 중간 보스가 늘어난다. 보상도 스테이지 번호만큼 커진다. 체력·공격·메아리 강화는 상한이 없다.

| 챕터 | 판 길이 | 중간 보스 (첫 바퀴) | 최종 보스 |
|---|---|---|---|
| 1 이끼 동굴 | 60초 | - | 슬라임 왕 |
| 2 해골 묘지 | 75초 | - | 리치 |
| 3 용암 광산 | 90초 | 슬라임 왕 (45초) | 화염 용 |
| 4 얼음 성채 | 105초 | 리치 (55초) | 얼음 군주 |
| 5 그림자 왕좌 | 120초 | 화염 용 (45초), 얼음 군주 (85초) | 그림자 왕 |
| 스테이지 6~ | 위를 반복 | 바퀴마다 1명씩 늘어남 (최대 3명 추가) | 같음, 체력 증가 |
| ♾ 생존 모드 | 끝없음 | 60초마다 강해지며 반복 | 없음 (스테이지 5 클리어 후 해금) |

  중간 보스를 잡으면 보물 카드를 준다. 생존 모드는 쓰러질 때까지 버티는 기록 경쟁이다.
- **보스 5종, 패턴 3가지**: 점프 착지(슬라임 왕·얼음 군주), 순간이동·소환·부채꼴 탄(리치), 회전 탄막(화염 용), 셋을 섞은 그림자 왕.
- **몬스터 7종**: 슬라임, 박쥐, 오우거, 해골 마법사(원거리), 멧돼지(돌진 예고), 왕방울 슬라임(분열), 꼬마 슬라임. 20초마다 정예 몬스터가 나오고, 잡으면 보물 카드를 준다.
- **카드 19장**: 일반·희귀·영웅 등급과 진화 카드 3장(폭풍검, 메아리 군단, 천둥 폭풍). 10초마다 1장을 고른다 (판이 길수록 카드가 많아져 빌드가 더 깊어진다).
- **메아리**: 챕터별로 최대 3명(강화하면 5명). 지난 판의 경로와 카드를 같은 순간에 그대로 재현한다. 독 발자국 같은 카드는 메아리도 남긴다.
- **원수**: 챕터별로 하나. 다음 판 25초에 이름표를 달고 나타나고, 복수하면 보너스 골드를 준다(최대 Lv.5).
- **메타**: 영구 강화 7종, 일일 임무 3개(매일 자정에 바뀜), 챕터별 최고 기록.
- **친구 메아리**: 결과 화면의 📤 메아리 공유로 이번 판을 코드로 보내고, 친구는 설정 › 친구 메아리 코드 넣기로 받는다. 그 챕터에서 친구가 이름표를 달고 함께 싸운다(슬롯과 별도로 1명). 받은 코드는 모든 값을 검사한다.
- **보상형 광고(선택)**: 쓰러지면 판마다 한 번 광고를 보고 부활(체력 절반), 결과 화면에서 광고를 보고 골드 2배. 강제 광고는 없다. 브라우저에서는 광고 없이 바로 보상된다.
- **편의**: 일시정지, 설정(효과음·음악·진동·화면 흔들림·이름), 안드로이드 뒤로가기, 앱이 백그라운드로 가면 자동 일시정지, 진동, 첫 판 튜토리얼.
- **소리**: 효과음과 배경음악 3곡(타이틀·전투·보스)을 모두 WebAudio로 합성한다. 음원 파일이 없어 저작권 문제가 없다.

## 실행과 테스트
```
npm install
npm run serve                 # http://localhost:8080 (방향키/WASD로도 조작)
npm test                      # 헤드리스 브라우저로 전체 흐름 검증
node tests/balance.mjs 160 2  # 봇으로 신규 플레이어 진행 곡선 측정
```

## APK
`main`에 push하면 GitHub Actions가 테스트를 돌리고, 통과해야 디버그 APK를 만든다.
Actions → **Build debug APK** → Artifacts의 `echo-dungeon-debug-apk`.
아이콘·스플래시는 `resources/`에 있고, `node tools/make-res.mjs`로 다시 만들 수 있다.
스토어용 512 아이콘과 1024×500 피처 그래픽은 `resources/store/`에 있다.

로컬에서 만들 때 (JDK 21, Android SDK 35 필요):
```
bash tools/android-prep.sh                 # android/ 생성, 아이콘·세로 고정·광고 앱 ID·버전
cd android && ./gradlew assembleDebug
```

## 출시 (Play 스토어용 AAB)
1. 업로드 키를 한 번 만든다. **이 파일과 비밀번호를 잃어버리면 앱을 업데이트할 수 없으니 안전한 곳에 백업한다.**
   ```
   keytool -genkeypair -v -keystore upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
2. GitHub 저장소 Settings › Secrets and variables › Actions에 넣는다:
   `KEYSTORE_BASE64`(`base64 -w0 upload.jks`의 결과), `KEYSTORE_PASSWORD`, `KEY_ALIAS`(위 예시는 upload), `KEY_PASSWORD`,
   `ADMOB_APP_ID`(AdMob 콘솔의 앱 ID, `ca-app-pub-...~...`).
3. `www/js/native.js`의 `AD_REWARD_ID`를 AdMob 콘솔의 실제 보상형 광고 단위 ID로 바꾼다. (지금은 Google 테스트 ID)
4. `package.json` 버전을 올리고 `git tag v0.5.0 && git push --tags` → Actions의 `echo-dungeon-release-aab`를 Play Console에 올린다.
5. 개인정보처리방침: `www/privacy.html`(게임 안 설정에서도 열림)의 연락처 이메일을 채우고, 같은 내용을 웹에 올려 Play Console에 주소를 적는다 (예: GitHub Pages).

## 이미지 교체 (Cloudflare Workers AI)
`www/assets/<이름>.png`(정면), `<이름>_b.png`(뒷모습), `<이름>_s.png`(오른쪽 옆모습)가 있으면 그 이미지를 쓰고, 없으면 코드로 그린 치비 캐릭터로 대신한다. 걷기·숨쉬기·공격 모션은 그대로 적용된다. 이미 있는 파일은 건너뛰고, 다시 만들려면 `--force`.
```
CLOUDFLARE_ACCOUNT_ID=... CLOUDFLARE_API_TOKEN=... npm run art          # 전부
CLOUDFLARE_ACCOUNT_ID=... CLOUDFLARE_API_TOKEN=... npm run art hero     # 하나만 (앞·뒤·옆 3장)
CLOUDFLARE_ACCOUNT_ID=... CLOUDFLARE_API_TOKEN=... npm run art icons    # 카드·강화·직업 아이콘
CLOUDFLARE_ACCOUNT_ID=... CLOUDFLARE_API_TOKEN=... npm run art bg       # 챕터별 투기장 전체 그림 (576x1024)
```
화풍 문구는 `tools/gen-art.mjs`의 `STYLE`에서 바꾼다. 토큰은 Workers AI 권한만 주고 저장소에 올리지 말 것.
