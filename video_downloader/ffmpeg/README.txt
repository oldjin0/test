이 폴더에 ffmpeg.exe 와 ffprobe.exe 를 넣어 주세요.

- 다운로드: https://www.gyan.dev/ffmpeg/builds/ (ffmpeg-release-essentials.zip)
  또는 https://github.com/BtbN/FFmpeg-Builds/releases
- 압축을 푼 뒤 bin\ffmpeg.exe, bin\ffprobe.exe 를 이 폴더에 복사합니다.
- build.bat 으로 EXE를 만들면 이 파일들이 자동으로 EXE 안에 포함됩니다.
- python main.py 로 실행할 때도 이 폴더의 ffmpeg 를 자동으로 사용합니다.
